# R1 release acceptance contract

Working source for #173 and the coordinating release epic #174.

## Scope

- Work management, resident communications, technician workflows, assets, attention,
  global search, and integration health.
- Roles and capability behavior documented in `docs/architecture.md` and `docs/api.md`.
- Seeded demo setup and verification sequence documented in `docs/RELEASE-TESTING.md`.

## Go/no-go checklist

- [ ] Supported workflows and role matrix reviewed against the current build.
- [ ] Seeded demo login and data verified from a clean database.
- [ ] Mock communications/integrations and deferred hardening are called out in release notes.
- [ ] QA, documentation, PDF, and release-mechanics evidence linked from #174.
- [ ] No unresolved release-blocking failures remain.

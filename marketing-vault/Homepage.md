## Where to put new work

| If you are adding… | Put it in… |
| --- | --- |
| A new source-backed finding | `Research/` and add it to [[Research/Research Index]] |
| A decision, plan, or approved operating guide | `Plans/` |
| A hypothesis and its result | `Experiments/` |
| A meaningful work-session record | `Sessions/` and update [[Sessions/Session Index]] |
| Brand or product truth | Update the relevant `Brand/` or `Strategy/` note |
| Recurring work | `Schedules/` |
| Draft content | The relevant workbench task or content ledger |

## Vault rules

- Use **Averion Software** for the company, **Averion Compass** for property management, and **StellaAI by Averion Software** for the separate crypto-trading product.
- Keep product claims tied to current evidence. Mark assumptions as hypotheses and unconfirmed capabilities as unknown.
- Do not store credentials, API keys, restricted personal data, or secrets in the vault.

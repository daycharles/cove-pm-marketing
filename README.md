# Cove PM marketing site

Standalone static marketing site for Cove PM, the property management suite with Autopilot.

The site is intentionally dependency-free: `index.html` is the deployable entry point and `.openai/hosting.json` preserves the connected Sites project.

## Local preview

Serve this directory with any static file server, for example:

```bash
npx serve .
```

## Content notes

Pricing benchmarks link to public pricing pages from Buildium, DoorLoop, and AppFolio. The snapshot is dated in the page and should be refreshed when the plans are reviewed.
